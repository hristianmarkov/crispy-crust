# Crispy Crust SEO and AEO implementation

Implementation date: 10 November 2026. Canonical public origin: https://www.crispycrust.app/.

This implementation treats the supplied playbook and 50-article collection as reference material. The current request replaces the staged release calendar: the website code and supplied article collection are implemented together. It does not turn proposed experiments, recipe tests or future product features into completed facts.

## Verification

`tests/seo.spec.ts` checks the complete 53-guide inventory, canonical and social URLs, unique metadata and images, Article dates, breadcrumbs, sitemap coverage, hub and tool routes, legacy-host path/query redirects and real 404s. Browser scenarios exercise the feeding, hydration and rise calculations; invalid inputs and reset; scheduling conflicts and CSV export; discard filters; every PDF download; narrow-screen overflow; and selected accessibility audits.

The numerical checks include the playbook's 175 g feed (35 g seed, 70 g flour, 70 g water), 72.7% total hydration including a liquid starter, a 50%-hydration stiff-starter case, 50% measured rise and a negative net rise. Scheduling checks preserve the full cooling interval, cross midnight and expose an availability window with no fitting schedule.

The production build passed. The final local Playwright run passed all 18 relevant tests in 27.1 seconds; only the unchanged signup persistence/removal test was excluded because it needs production backend credentials. Invalid-signup and cross-origin rejection checks passed. The final source inventory and all internal HTML links were checked. Mobile screenshots of the journal and embedded rise calculator were visually inspected at 390 × 844 with no observed layout issue. These checks do not establish that a production deployment is live, that a search engine has indexed it, or that a tracking event reached an enabled analytics account.
